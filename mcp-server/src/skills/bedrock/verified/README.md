# Bedrock Verified Skills

This directory will contain production-ready skills for Minecraft Bedrock Edition bots.

Currently, all skills are Java Edition only. Bedrock skills are under development.

## Planned Skills

The following skills will be adapted for Bedrock Edition:
- Basic movement and navigation
- Chat and communication
- Simple block interaction
- Inventory management (limited by Bedrock protocol)

## Contributing

To contribute Bedrock skills, please ensure they:
1. Work with the bedrock-protocol library
2. Follow the same structure as Java skills
3. Handle Bedrock-specific limitations
4. Include proper error handling
